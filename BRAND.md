# GDZIEKIBEL.PL — Brand System v1

Status: Approved creative direction  
Reference visual: `docs/design/reference/gdziekibel-approved-direction.png`

## 1. Brand idea

**Warszawa nie trzyma. My znajdujemy kibel.**

GdzieKibel.pl should feel like a piece of Warsaw street infrastructure that has somehow developed a personality.

It is not polite municipal communication. It is a fast public utility with the bluntness of a friend who understands the emergency.

Creative equation:

> WARSAW URBAN BRUTALISM  
> × STREET / TRANSIT SIGNAGE  
> × POLISH INTERNET HUMOUR  
> × HIGH-QUALITY CONSUMER PRODUCT

## 2. Brand character

The brand is:

- blunt,
- impatient in a useful way,
- funny,
- urban,
- local,
- self-aware,
- slightly rude,
- practical,
- confident.

The brand is not:

- childish,
- random meme spam,
- corporate,
- cute,
- pseudo-luxury,
- generic SaaS,
- edgy for the sake of being offensive.

## 3. Tone rule

### The key rule

**Be vulgar enough to be memorable, but never so clever that the user has to decode the interface.**

Strong copy belongs mainly in:

- hero lines,
- empty states,
- loading lines,
- supporting captions,
- campaign/social creative.

Literal copy belongs in:

- opening status,
- price,
- accessibility,
- distance,
- navigation actions,
- legal/privacy information.

## 4. Profanity ladder

Use three levels deliberately.

### Level 1 — direct

Default for ordinary UI.

Examples:

- `CHCE CI SIĘ SRAĆ?`
- `TU JEST KIBEL.`
- `3 MIN PIESZO.`
- `PROWADŹ MNIE.`
- `ZA DARMO. CUD.`

### Level 2 — rude/funny

Use for secondary copy and notable states.

Examples:

- `3 MINUTY. DUPA W TROKI.`
- `PŁATNY. BO OCZYWIŚCIE.`
- `NIE PANIKUJ. JESZCZE ZDĄŻYSZ.`
- `TEN WYGLĄDA NA NAJMNIEJ ZŁY.`
- `MASZ KILKA OPCJI. WYBIERAJ MĄDRZE.`

### Level 3 — hard punchline

Use sparingly. Never stack multiple Level 3 lines on one screen.

Examples:

- `ZAMKNIĘTY. NO KURWA SUPER.`
- `NIE MA NIC BLISKO. PRZEJEBANE.`
- `KIBEL ZNIKNĄŁ. PIĘKNIE.`
- `LOKALIZACJA NIE DZIAŁA. JA PIERDOLĘ.`

Production rule: one Level 3 line maximum per screen/state, and always pair it with a useful next action.

## 5. Writing principles

### 5.1 Short wins

Bad:

> Niestety nie udało nam się odnaleźć żadnej dostępnej toalety publicznej w Twojej najbliższej okolicy.

Good:

> `NIC BLISKO.`  
> `Rozszerz wyszukiwanie.`

### 5.2 Say what is true

Do not turn uncertain data into a joke that sounds authoritative.

Bad:

> `NA PEWNO OTWARTY.`

when data is uncertain.

Good:

> `RACZEJ OTWARTY.`  
> `Godziny nie są w 100% pewne.`

### 5.3 Do not insult the user

The tone may be rude, but the user is not the target.

Prefer:

- `Warszawa znowu utrudnia życie.`

Over:

- `Nie bądź debilem.`

### 5.4 Punch up at the situation

Targets for humour:

- bad city luck,
- closed toilets,
- absurd pricing,
- urgency,
- bureaucracy,
- the universal need to pee/poop.

## 7. Brand visual cues

Core motifs:

- oversized condensed typography,
- Warsaw street sticker / poster energy,
- signal-yellow rectangles,
- black/dirty-white contrast,
- hand-written hot-pink accent used sparingly,
- simple pictograms,
- utilitarian map UI,
- print-registration / torn-paper / marker textures only outside critical UI areas.

## 8. Logo direction

Primary wordmark:

`GDZIEKIBEL.PL`

Preferred properties:

- uppercase,
- condensed/bold,
- works in one colour,
- legible at favicon/header scale,
- no toilet emoji inside the primary wordmark.

Possible campaign lockup:

`GDZIE`  
`KIBEL`  
`.PL`

stacked as a poster device.

## 9. Colour direction

Final tokens are owned by `DESIGN.md`, but the brand palette is:

- near-black,

## 11. Copy QA checklist

Before shipping copy, ask:

1. Is the factual meaning obvious in under one second?
2. Is the joke secondary to the action?
3. Are we insulting the situation rather than the user?
4. Are unknown values represented honestly?
5. Is there only one dominant punchline on this screen?
6. Would the screen still work if the funny line were removed?

If not, rewrite it.
